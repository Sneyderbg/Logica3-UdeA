# Lógica III - Librería en Java

Este repositorio contiene una **librería en Java** desarrollada como parte del curso de **Lógica III** de Ingeniería de Sistemas en la Universidad de Antioquia.

## Contenido

La librería incluye implementaciones de estructuras de datos utilizadas en lógica computacional, entre ellas:

- Árboles binarios y AVL  
- Grafos  
- Listas generalizadas y listas ligadas  
- Matrices dispersas  
- Representación de nodos  
- Operaciones con polinomios  

## Requisitos

- Java 8 o superior  
- Gradle (opcional, ya que se incluye el wrapper)

Esta librería puede ser utilizada como base para proyectos académicos, ejercicios de práctica o como referencia para implementar estructuras de datos en Java.
